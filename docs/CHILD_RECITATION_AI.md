# Child recitation AI
Existing: `/me/recitations/analyze` (Whisper word alignment against the stored approved text, never stores audio, reports pronunciation/tajweed as not assessed, returns `insufficient_evidence` on weak input; verified live with a silent clip). Homework can attach a student's own attempt as a labelled machine hypothesis (never a grade, never blocks submission).
Not built: letter-level or word-level pronunciation feedback for children, a corrective model audio, child-voice accuracy measurement, noise testing. Whisper is a general speech recogniser and was not evaluated on children's or tajweed recitation; no accuracy claim is made. Minors' recordings stored for teachers require a live guardian consent (DB trigger); the personal analysis path stores no audio.

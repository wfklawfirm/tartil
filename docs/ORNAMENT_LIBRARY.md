# Ornament library (V3)

Canonical description and parameters: `docs/04_ORNAMENT_LIBRARY.md`; live samples at `#/gallery` (development route).

Assets are generated SVG: {8/3} lattice (C), 8-point star tessellation (A), vegetal vine (B), manuscript corner, divider, ayah marker, surah cartouche, 24-petal medallion. Ayah, stage and timeline markers are inline SVG (not CSS backgrounds), because iPhone did not paint the CSS-variable background version.

Honest assessment: these are original, mathematically regular but simple. They do not reach the richness of the Met manuscripts in the benchmark (no hand-drawn arabesque, no interlaced polygons beyond the {8/3} lattice). Raising them to museum quality needs a human illuminator/designer; this is listed in the release-readiness matrix as a remaining item.

Density per context: decorative (hero, certificates), balanced (learning, tajweed), minimal (reader text, dashboards, admin).

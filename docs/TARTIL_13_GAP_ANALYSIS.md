## 3. Cross-cutting findings

1. **Largest functional gap = Academy is read-only content with device-local progress.** Learner state, reflections, missions, observations and reviewer sign-off all have backend tables (0017) but no screen and no production deployment. Until both exist, "teacher / parent / institution paths" for the Academy are not real paths.
2. **Largest blocker = people, not code.** No scholarly, pedagogical or child-protection reviewer exists; the retention policy is unwritten; the safeguarding lead is not named. These cap every content row at NEEDS SCHOLARLY REVIEW regardless of engineering.
3. **Largest risk = production drift.** Three migrations and several routes exist only in the repo; the lag between repo and live is the likeliest source of surprises (the earlier `Buffer` defect is the precedent).
4. **Security items that should not wait for features:** password recovery/admin reset, a tenant admin self-assigning `scholarly_reviewer`, unrevocable-until-expiry membership suspension, trusted context injection.
5. **Data in hand but unwired:** X1–X5 gap units (28 lessons), 16 teacher/parent guides (shown as data, usage in UI not verified beyond E2E loading), principle extraction for the Heritage lab.

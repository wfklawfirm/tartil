# سجل مراجعة الجودة المستقلة: أدلة المرشد/ولي الأمر P13 وP14 وP15 وP16

**الملفات:** `guides/P13.json`، `guides/P14.json`، `guides/P15.json`، `guides/P16.json`. **المعيار:** `CLAUDE.md` و`PEDAGOGY.md` وبيانات `programs.json` (الأعمار، المدة، المراحل، الحواجز) وعناوين الدروس والسيناريوهات في `lessons/`.
**الطريقة:** قراءة كاملة لكل نص، وإصلاح العيوب الواضحة بأقل تعديل مع بقاء المفاتيح وعدد الأسابيع. نسخة احتياطية في scratchpad قبل التعديل. التحقق: الملفات الأربعة JSON صالحة، وعدد `week_by_week` = `duration_weeks` (8 و8 و4 و4). حالة المراجعة تبقى `unreviewed`؛ هذه المراجعة لا تحلّ محل المراجعة العلمية أو التربوية أو مراجعة الحماية.
**ما سلم من الفحص:** لا آية أو حديث حرفيًّا ولا فتوى (الأسئلة الشرعية والقانونية تُحال)؛ لا درجات ولا ترتيب ولا مقارنة؛ لا ألفاظ واصمة؛ لا نصيحة طبية أو مالية؛ لا جمع بيانات (التأمل خاص)؛ لا ادعاء مراجعة (P14 وP15 وP16 تنص صراحة على أنها مسودة)؛ مطابقة الأعمار والمدة والإيقاع وعناوين السيناريوهات لبرامجها.

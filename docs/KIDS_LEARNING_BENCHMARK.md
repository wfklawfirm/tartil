# Kids learning benchmark
Observed 2026-11-03 by fetching each public landing page (text only). Nothing was copied; no assets, characters or models were taken. Licence/terms for each product are NOT stated on the pages reviewed, so nothing here is cleared for reuse.

Takeaways: every reference pairs recorded human audio with the visuals. Tartil has no cleared audio, so the audio-first activities are deliberately absent rather than faked with synthetic speech.
